# Noma Living | نُوما

A responsive Persian RTL furniture and bedding storefront concept. Original visual identity inspired by the category structure of tolica.ir and the simplicity of rost.ir; no affiliation with either brand.

## Features
- Fully Persian, responsive layout with locally hosted Vazirmatn font and photography
- Product categories, normalized Persian search, price sorting and favorites
- Product dialog with color options, local cart, quantity editing and calculated totals
- Editorial articles, accessible native dialogs, keyboard navigation and reduced-motion support
- No framework, build step or runtime dependencies

## Run
Open `index.html`, or run `python3 -m http.server 8080` in this folder.

## Demo scope
All products, prices, dimensions and product names are illustrative. Images are illustrative and do not change with the selected color. Cart and favorites persist in localStorage only. There is no payment, authentication, backend, inventory, order submission or customer data collection. The order review explicitly explains this.

For a real store, connect a backend, verified product catalog and inventory, payment gateway, shipping calculation, order management and approved business policies.
